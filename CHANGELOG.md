# Nouveautés

Chaque version publiée a sa section `## vX.Y.Z`. Le workflow « Publier une version » en reprend le
texte pour la release GitHub et pour la notification de mise à jour dans l'application.

## v0.3.2

- Première version installable de la mise à jour automatique (les releases v0.3.0 et v0.3.1
  n'ont pas d'installeur). À installer à la main une fois : les versions suivantes seront proposées
  directement dans l'application.

## v0.3.1

- Release sans installeur (publiée par erreur à la main) : utiliser la v0.3.2.

## v0.3.0

- Mise à jour automatique : à l'ouverture, l'application signale une nouvelle version et propose
  « Mettre à jour » ou « Plus tard ».

## v0.2.0

- Import / export SimaticML du LADDER avec TIA Portal (export réglé pour la V20, expérimental).

## v0.1.0

- Première version : bibliothèque de snippets LADDER / SCL / LIST, éditeur LADDER visuel,
  import / export zip et sources TIA .scl / .awl.
